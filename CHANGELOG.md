# Changelog

All notable Hostplan releases are documented here.

## 0.1.0 - 2026-07-28

Initial public release.

- Store coding-agent plans locally by Git project and branch.
- Share stable private or public plan URLs through a hosted deployment.
- Read plans back by id, URL, or current project and branch.
- Track lifecycle status, task completion, revisions, and ordered plan stacks.
- Hand plans to Codex, Claude Code, and Cursor.
- Run a local human- and machine-readable web viewer.
